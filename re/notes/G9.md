# G9 - low-level graphics library (segments 0d84..1172)

## Buffers & conventions
- All image buffers: 320x200 8bpp, pitch 320, 64000 bytes. `DSPTR(0x2d38)` draw buffer, `DSPTR(0x2d3c)` screen (VGA A000),
  `DSPTR(0x3056)` background/scroll-source. Play view = rows `DS16(0x303c)`(0) .. `DS16(0x3054)`(172) excl.; below = UI.
- Row offsets always come from `SSU16(y*2)` (=y*320); some code uses it as a multiplier (`SSU16(k*2)` = k*320 bytes).
- **Clip rect (errata for PORTING.md):** `SS16(0x192)`=ymin, `0x194`=ymax, `0x196`=xmin, `0x198`=xmax, all inclusive
  (`sub_0fe6_01ac(xmin,xmax)`, `sub_0fe6_01bf(ymin,ymax)`, confirmed by line outcodes and sub_0596_02b7).
- Dissolves 017d/01c5 use only the *segments* of 0x2d38/0x2d3c (offset 0); text 1172_0012 uses only the segment of `dst`
  (offset treated as 0). Translate as base pointers. 1036_000a is a plain 64000-byte copy (not TC memcpy).
- Negative/out-of-range row offsets (e.g. sprite top y<0) wrap in 16 bits in the original: compute offsets as int32 and
  only form the pointer after clipping. Many loops are `dec; jne` (count 0 => 65536/256 iterations): assume >=1, comment.
- No Turbo C library functions here. 0f3a_0004 = custom itoa to static buf, 0f21_0004 = custom 32-bit LFSR PRNG.

## RLE sprite bank (0fe6_01d2, 115f_*, 1110_01bc; also shape prim 1)
```
bank:   u32 off[idx]                 sprite = bank + off[idx&0xfff]  (huge-pointer add; just bank+off)
sprite-2: u16 flags   bit15 = stored row data is currently mirrored (toggled when 01d2 mirrors data in place)
sprite+0: u8 w16  (width = w16*16 px)     +1: u8 h     +2: h rows, top to bottom:
row:    u8 nruns; nruns x { u8 skip; u8 n4; u8 n1; u8 pix[4*n4+n1] }; u8 trailing_skip   (skips+pixels = width)
```
- draw id: bits0-11 index, 0x8000 mirror, 0x4000 opaque (skips written as 0). (x,y) = left, **bottom** row (top=y-h+1).
- Unclipped transparent path copies run pixels verbatim (a 0 inside a run IS written); clipped paths decode the row into
  the 400-byte scratch (skips=0) then copy with "0 = transparent" (transparent mode) or verbatim (opaque).
- Mirror (01d2, when `(id ^ flags) & 0x8000`): per row, rewrite in place: nruns kept, first skip <-> trailing skip,
  run order reversed, each run's pixels reversed, (n4,n1) kept; then flags ^= 0x8000. **Bank data must be writable.**
- 1110_01bc output: `u32 6; u16 flags(copied); u8 new_w16; u8 kept_rows; rows...`; column pickers per level L (of each 16):
  L0 {6} L1 {6,14} L2 {4,9,14} L3 {2,6,10,14} L4 {1,4,8,11,14} L5 {0,3,6,9,11,13} L6 {0,2,4,6,9,11,13} L7 even cols
  L8 {0,2,4,6,8,9,11,12,14} L9 {0,1,3,5,6,8,9,11,12,14} L10 {1,2,4,5,6,8,9,10,12,13,14} L11 {0,1,2,4,5,6,8,9,10,12,13,14}
  L12 {0-6,8,9,10,12,13,14} L13 {0-6,8-14} L14 {0-6,8-15}; new_w16=((L+1)*w16+15)>>4; decimated row + 16 zero bytes then
  re-encoded with `repe/repne scasb` over new_w16*16 px - emulate exactly (a run touching the row end loses its last px);
  an all-empty row is written as `01 00 00 00 skip`.

## Vector shape file (106a_0477/04ff/0593/06a1)
```
file+0: u16 dir_off   file+4: u16 sprite_bank_off (for prim 1)   dir = file+dir_off, entry i (4 bytes): u16 off -> shape = dir+off
shape:  u8 flags (0x10 = coords are int8, else int16); u8 nprims
prim:   u8 type; u8 n; u8 colA; u8 colB; n x (x,y)  -> vbuf[i] = decode(x)+X, decode(y)+Y
```
- id arg: bits0-11 shape index; high byte & 0xa0 ORed with shape flags: 0x80 negate x, 0x20 negate y (applied before
  scale/offset). 04ff: v*scale>>8 (bits 8..23 of the imul). 0593: rotation, ignores flags (always int16, no negate).
- types: 0 sub-shape, 1 sprite, 2/3 skip, 4 polygon, 5 box, 6 polyline, 7 points (see protos). colA 0xff = no outline.
- Morph (06a1): shape = dir entry 0; `u8 ?; u8 nprims`; prim `u8 type; u8 n; u16 colsA; u16 colsB; n x (xa,ya,xb,yb)`;
  thr=(t*nprims)>>8 (mul unsigned); prim counter c=nprims..1 uses colsA if c>=thr else colsB (lo=colA, hi=colB).
- Handlers get `n` in dx, may move `si` (type 2/3), and read caller's `shp` ([bp+0xc]); they use colA/colB statics and
  **cs:0xc (0477's last flags) even when called from 04ff/0593/06a1** - keep that quirk. Recursion (type 0) re-enters 0477.

## Bitmap font (1172)
```
font+0: u8 first_char  +2: u8 height  +3: u8 stride (0 => u16 stride at +4)  +6: u16 BIG-endian glyph table offset
font+8: bitmap, 1bpp MSB-first, `stride` bytes per row, height rows (all glyphs side by side)
glyph[c - first]: u16 BIG-endian: bits12-15 width (0 = space), bits0-11 x bit offset in bitmap
```
- draw: rows top-down at (pen_x, y), set bits -> color, no clip; advance = w+1 (space: 3). Width fn: same metric.

## Palettes
- 768-byte RGB. Files are 8-bit, converted in place by 0e3f_00de (>>2). 0dc5_03de writes a 32-step gradient into entries
  224..255, 0dc5_022e paints color-15 sky pixels of bgbuf with 0xFF..0xE0 (2-row bands) to use it. 0448 = tint (0..15).
  Values can exceed 63 (0448 adds +100): VGA DAC keeps low 6 bits -> plat_set_palette must mask `& 0x3f`.

## Self-modifying code -> C
- 0d84_0002: imms dx,dy (0x62,0x6f), ymin/ymax (0x18e,0x194), edge table base (0x1a5), color (0x215) -> locals/statics.
- 106a: opcode patches (lodsw/nop <-> lodsb;cbw / neg ax) are pure functions of the flag byte: 0407/043f just store
  `static uint8_t s_flags477 (cs:0xc), s_flags4ff (cs:0xd)`; decoders test the bits. 0593 imms (cos,sin,X,Y) -> locals.
- 1172: imms y, height, x, bitmask, color, stride -> statics set by 011d / locals in 0012; 0xc3=1, 0xd3=2 are constants.
- Scratch/state areas in code segments (0fe6:000a[400], 1110:000c[320], 106a:001f vbuf[500 i16]) -> static arrays.
- `jmp $+2` after patches = prefetch flush, ignore. `cli/sti` ignore. Full list in re/globals/G9.txt.

## Platform calls needed
- `void plat_set_palette(uint16_t first, uint16_t count, const uint8_t *rgb6)` (0e3f_00be; mask &0x3f).
- `void plat_wait_vsync(void)` (0e3f_0104, also 118f_00de in G10): present screen + wait next 70 Hz tick + pump events.
- `uint8_t *plat_screen(void)` - 64000-byte framebuffer that DSPTR(0x2d3c) points to (VGA A000:0000).
- `void plat_present(void)` - after direct screen writes (0dc5_0148, 026b/02dd/0355, dissolve passes, text on screen).
- `void plat_get_time(uint8_t *h, uint8_t *m, uint8_t *s)` (0dc5_0780, DOS int21/2Ch).
- `int32_t plat_file_size(const char *dosname)` (0f23_000a; -1 if missing) - or the G-file layer's open/seek/close.
