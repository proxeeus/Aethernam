# G4 – segment 0596: room rendering, speech bubbles, animation player

**Role.** The per-frame presentation layer of the adventure screen. The main loop (sub_0053_1e8e) calls
`1252` (draw room contents), `0687` (speech bubble), `0767` (choice menu, if [0x3240]) and `0059`
(FX + copy draw buffer to screen). Room change (sub_0053_1298) calls `169f` (rebuild static background into
DSPTR(0x3056)) and optionally `09d5/09de` (horizontal scroll transition). Script op 0x1f/0x51 calls `0f41`
(full-screen PAK animation with sound cues).

**Buffers.** DSPTR(0x2d38) draw buffer, DSPTR(0x2d3c) screen, DSPTR(0x3056) room background (restored every
frame elsewhere), DSPTR(0x17b4) 64K backdrop load buffer, DSPTR(0x3294) morph work buffer. Play area is
y=[0x303c]..[0x3054]-1 (0..0xab); bottom panel y=0xac..0xc7.

**PAK resource layout** (helpers in 0053): file = table of u32 offsets. `052f(i,p)` = p+off[i];
`0564(i,j,p)` = sub-entry j of entry i; `0994(p)` = entry 4 (768-byte palette, present when first offset == 0x14).
Sprite banks (106a_*) use entry 0; entry 1 holds packed images (sub_0fe6_01d2); entry 2 holds anim sequences
(`0b11(seq,p)`): +1 u8 frame count, frames of 8 bytes from +2: `+0 sprite, +2 (type<<14 | param), +4 dx, +6 dy`
(dx/dy are cumulative). Frame type 0 plain, 1 morph to next frame in `param` steps (0a21_0005 + 106a_06a1 with
weight `(step<<8)/param`, unsigned), 2 sprite with param (106a_04ff), 3 shaded (106a_0593, param&0xff).
Files: A??.PAK (DSPTR 0x18a0, animations, loaded via 0053_0413), D??.PAK (DSPTR 0x18a4, backdrops, via 0fa2_0008).

**Actor record** (0x11a + i*0x46): +0 x, +2 y, +0xc room, +0xe anim state, +0x10 anim type (2 morph),
+0x12 kind, +0x16 fptr PAK, +0x1a seq, +0x1c frame, +0x1e morph step, +0x20 nframes, +0x2c u8 text colour,
+0x3c/+0x3e clip x1/x2, +0x40/+0x41 u8 clip y1/y2.

**Room drawing.** Room pack DSPTR(0x3286): sprite room*2 = background, sprite room*2+1 = foreground sprite
OR (when its byte +1 == 0) a list of 8-byte "pieces" `{u8 kind(1=packed image),pad, w idx, w x, w y}`.
`13bb(room,slot)`: backdrop from table 0xbbc (pak entry/sprite per slot; loads palette if present) then bg.
`1564`: parallax – [0xc6]==1: room [0xbc0] shrunk 1/2 into 0x3056 at ([0xbc6],[0xbc8]); [0xc6]==2: room [0xbc0]
shrunk 1/4 there, plus room [0xbca] shrunk 1/2 at ([0xbd0],[0xbd2]); colour 0 transparent. `1252` walks the depth-sorted draw list
DSPTR(0x3270) (+0 u8 count, 2-byte records from +3; code hi-nibble 0 actor, 1 next foreground piece, 2 projectile
slot 0x692). `171e` draws exit markers for zones of type 3 (table 0x752).

**Speech.** Text block = up to 3 NUL-terminated lines per page, block terminated by '*'. `0405` measures a
page (half width [0x30aa], height [0x30ac], timer [0x328a] = sum(width/4), more-pages [0x17be], next page
DSPTR(0x3028)); `04b7` draws the bubble frame (fill 0x1a, borders 0x43/0x45, corners bank 0x3066); `033e`
draws the lines. Choice menu: table 0x306a (6 x 10 bytes), selection [0x3274].

**FX mode [0x10c]:** 1 reflection of hero (actor 1 drawn with hero anim via 0053_0cf2 + map 0x1abc, clipped into
rects (0xae,0x6c)-(0xc1,0x88) and (0xc0,0x64)-(0xe0,0x88)); 2 mirror at ([0x3036],[0x3038]) 7x25 px (`09e7`);
3 particles until [0x3260] runs out. Room 0x17 palette pulse; room 0x13 random sparkles (`11cf`).
Present modes in `0059`: dirty rect, plain copy, or zoom 2x/3x/4x ([0x177c]) around the hero.

## Tricky for the port
* `033e`: when mode != 0 the local `half` ([bp-0xa]) is never initialised. On DOS it holds the CS word of the
  far return address left by the preceding 04b7 call chain (always non-zero), so **every line is drawn and y
  advances**: translate as "mode != 0 => draw". Mode 0 skips empty lines without advancing y.
* `11cf`: argument evaluation order matters for rand(): compute `rand(h)+y1` first, then `rand(w)+x1`, then
  `rand(2)+0x67` (original push order).
* `0965` reads back the VGA screen (DSPTR 0x2d3c) into the draw buffer: platform must keep a readable shadow.
* `1614` uploads 16 DAC entries via sub_118f_01ab (port I/O, other group) – palette 0xa0..0xaf.
* `0f41` is a modal frame loop (present 118f_0107, frame limiter 0053_1e2e, pause 0053_05cd). It polls
  DS8(0x2d4e) once per frame (no tight busy-wait in this segment) – but the loop must reach plat code each
  frame (it does via 118f_0107/0053_1e2e). Key 0x1c re-read live after saving it for the Esc test.
* `0001`: farcoreleft (DOS 48h) check before farmalloc(0xFFFF) – port: just allocate.
* `1564`: offsets `y*320+x` computed in 16 bits (imul) and added to the far pointer offset – use `(uint16_t)`.
* `0b28`: `(uint16_t)(step<<8) / (uint16_t)param` (unsigned `div`); param forced to 1 if 0 (only for the div).
* `0cca`: bytes +0x23/+0x24 loaded but unused (dead loads).
* Clip rect in SS: 0x192 ymin, 0x194 ymax, 0x196 xmin, 0x198 xmax (PORTING.md lists them as x,x,y,y).
* Unlisted dead functions in the gap: `sub_0596_0f03` (= 0e96) and `sub_0596_0f08` (draws panel on screen and
  buffer); unreferenced (no far pointer 0596:0f03/0f08 in the image). Prototyped in G4.h.
