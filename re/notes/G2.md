# G2 – segments 026c / 02a7

## 026c – projectiles (shots)
* 16 slots at DS:0x692, 12 bytes: `+0 u8 used(0xff=free) +1 s8 owner +2 s16 age(-1 flying, 0..8 impact)
  +4 s16 rand(128)+0x20 +6 x +8 y +0xa dir(1 up,2 right,3 down,4 left)`.
* Player fires when char0 anim state (0x128)==8 and frame (0x136)==1 (`038b`). `0237` moves shots
  (15 px/frame horizontally, 5 px vertically), hit box (x-8,y-4,x+8,y); collision vs characters
  `sub_0714_03d2(owner,rect)` (returns 0x600|idx, masked &0xf) and walls `sub_0714_031f(rect,dir)`.
  Hit -> `010d`: knockback 32 px (validated by `sub_0714_0160` floor clamp, `03d2`, `04a0` obstacles),
  hp -= damage (`sub_0791_0638`), particle burst `sub_0791_020d(x,y-10,10,15)`, fx mode [0x10c]=3.
* `034a` feeds shots into the depth-sorted draw list (`sub_0053_075b(y, 0x20+slot)`).
* Character table 0x11a, 10 x 0x46 bytes (see globals), player = entry 0.

## 02a7 – interface
1. **Status message** (`0006`/`0098`): kind + item, 20 frames; text = string 0x36+kind of the
   '*'-separated table DSPTR(0x3290) (`sub_03dd_165d(idx,table)`), item name appended for kind<4.
   Kinds used: 2 taken, 3 used, 4 can't take, 5 nothing here, 6 nothing seen. Bevelled box `001d`.
2. **Action bar** (`127c` modal loop, state [0x3266] 0..4): icons T,U,L,S,I,D (scancodes 0x14,0x16,
   0x26,0x1f,0x17,0x20), Tab toggles, Enter/fire confirms, Esc -> quit prompt. Bar slides y 0xd4<->0xb8
   2 px/frame, cursor x slides 2 px/frame to table 0x179a. After closing it calls far fn
   `DSPTR(0x1782 + 4*action)`: 0 Take `0f92`, 1 Use `1066`, 2 Look `1044`, 3 Speak `1038`,
   4 Inventory `103f`, 5 Disk `108d`. Those 6 have no direct callers – only via this table.
3. **Hotspots / look** (0xa18, 8-byte entries, count [0xf0]): zone in front of player `0d46`;
   `sub_0714_0559(rect)` returns 0x500|idx of an unowned-item hotspot. `0e21` runs every frame:
   walking in front of an undescribed hotspot shows its text (`0d09` -> `sub_0596_0405`) and starts
   a 20-frame "look" with a scan beam (`0c92`, drawn by seg 0596 renderer).
4. **Items**: state array 0xfbc[256] s16 (0 none,1 owned,2 equipped,3 used this turn).
   Cursor [0xb8], equipped [0xba], list top [0xbc], count [0xbe].
5. **Inventory/status screen** `0bb5` (action I): background glyph 0xa of bank DSPTR(0x3062),
   palette = sub-resource 4 of that bank (`sub_0053_0994`), labels "Time/Name/gp/%/Don JONZ",
   play time from s32 [0x1fdc] = hhh:mm:ss + 1/20 s (T/1200/60%999, T/1200%60, T/20%60, T%20), gold [0x11c6],
   completion (`sub_0c05_020c` = bit count of 13 flag bytes at 0xf6), list of 12 items, and an
   animated **ECG heartbeat** (50 points at 0x30ae, drawn straight onto the screen; beat rate from
   HP: rest delay clamp(HP>>2,1,30)+rand(5)). 'V' key prints "Version Interne 14-04-92".
6. `07c8` 3-digit counter (glyph 0xd+d) used for the countdown [0x1fe6]; `0863/08f3` HP (0..99)
   in bottom bar; `0b4a(x1,y1,x2,y2)` = copy back-buffer rect to screen (used by many modules).

No resource files are loaded here (text tables, glyph bank and palettes are already in memory).

## Port hazards
* **Busy waits on interrupt-updated keyboard byte DS8(0x2d4e)** – need `plat_yield()`:
  `0bb5` (two `while (DS8(0x2d4e) != 0)` loops), `10e6` (`while (DS8(0x2d4e)==0x0f)` Tab release).
* **`0bb5` main loop has no frame wait at all** (no vsync, no timer): it polls input, redraws,
  increments play time per iteration – speed was CPU-bound. Port must `plat_yield()`/pace each
  iteration (else time counter and ECG run at thousands of fps). `127c` is paced by `1264`
  -> `sub_118f_00de` (vertical-retrace wait on port 0x3da, belongs to another group).
* `0351` and `08f3` temporarily redirect DSPTR(0x2d38) to the screen DSPTR(0x2d3c) and restore it.
* `0c92`: two `rand(3)` calls are argument expressions – original order: first for y2, then x2;
  evaluate into temporaries in that order. Same care in `026c_0067` (rand(9) then rand(128)).
* `0920` has no prologue and ends by tail-calling `04f1`; sigs guess "long" is wrong – void.
* `026c_0067` is called with ONE arg (sigs file says 2). `10e6` takes a byte (`mov ah,0`).
* Jump tables: `10e6` (key-0x1c, 11 entries: 0x1c Enter, 0x1f S, 0x20 D, 0x26 L, others default)
  and `127c` (state-1, 4 entries) -> switch statements.
* Far fn table 0x1782 (6 entries, all seg 02a7) must be registered as function pointers in DSPTR.
* Signed compares everywhere (jl/jg); `0319` tests `x - pt.x >= 0` (16-bit signed).
* `026c_0237`: `sub_0714_03d2(...) & 0xf` means character 0 can never be hit by a shot.
