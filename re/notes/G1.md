# G1 – segment 0053: main, level/room flow, resource cache, actors, input

## What it does
* `main` (2014): detects the CPU, reads the launcher parameter block (sound option, language), installs
  video/keyboard/timer/sound drivers, allocates buffers, starts music, seeds the RNG from the DOS time,
  runs game init (0be7), plays the intro level (1f74 with 0xa2=8, set by sub_03dd_1147), then enters the
  world loop `sub_0a86_154d`. It never returns: sub_0791_0665 shuts down and calls exit().
* Level loop 1f74 -> 1f21 (one frame) -> 1e8e (tick: keys, player control, animation, movement, depth
  list, render sub_0596_1252, present sub_0596_0059). Room change (1479) and level change (1568) are
  deferred through requested/current pairs: 0xd0/0xce (room), 0xa2/0xa0 (level). -1 = leave.
* Files: `A??.PAK` (sprites, cached, ?? = level), `D??.PAK` (level data, entry 0), `R??.CC4` (room scripts),
  `T.CC4` (encrypted texts; first letter = language from "TESDI"), `RESID.PAK` (#0 font etc., #1 player
  sprites), `MUS.PAK` (becomes `MUb.PAK` if launcher byte 7 == 0). sub_0925 writes the level digits into the names.
* Text decryption (0895): `buf[i] -= (uint8)(0x5f*(i+1))`, i counted as 32 bits.
* Resource block format: int32 offset directory; sub_052f(i,b) = b+dir[i]; sub_0564(i,j,b) is two levels.
  Level data: sub-block 4 = palette (768 bytes); sub_0564(0, room*2+1) = room object list
  {u8 ?, u8 count; count x 8 bytes {u8 type,pad, u16 image id(&0x7fff), s16 x, s16 y}}.
  Sprite sets: sub_0564(2, anim) = anim record: byte[1] = frame count, frames from +2, 8 bytes each
  {w0 image, w1 = (type<<14)|delay, w2 dx, w3 dy}. The image header (2 bytes before the image data) gives width/depth.
* RESID blocks contain relocated FAR POINTERS (sub_0c66_0003 turns offsets into pointers):
  0be7/0a6d read them with FP(p), FP(p+4), FP(p+8).

## Resource cache DS:0x928, 20 slots x 6: {s8 kind, s8 idx, fptr data}
kind 0 = A??.PAK entry idx (loaded by 0413, freeable); kinds 1,2,3,6,7 = pointers to preloaded blocks (03a5).
0483 = get (find, else use a free slot, else purge 028e then retry). Purge frees kind-0 slots not used by
a living actor of the current room (007e) and clears actor pointers (0168). Low memory (<20000 bytes, sub_0000)
also triggers a purge.

## Actor struct (0x46 bytes, table DS:0x11a, 10 entries, [0] = player)
+00 x, +02 y (s16) | +06/+08 world-map pos | +0c room | +0e state (0 stand, 4 walk, 8 action)
+10 anim-change flag (0 none, 1 pending, 2 locked) | +12 dir (1 up, 2 right, 3 down, 4 left)
+14 u8 enemy flag (1 = hostile) | +16 fptr sprite set | +1a anim | +1c frame | +1e frame delay counter
+20 frame count | +22 u8 0xff = animating | +23 u8 half width | +24 u8 depth | +25 u8 collision type
(8 = ignore collisions, 4 = door) | +26 u8 collided door/object index | +28 u8 sub-state | +2a hit points
(nonzero = alive; player max 99, NPC 10) | +2c u8 | +30 u16 walk flags (bits0-1 axis, bit2 has waypoint
+38/+3a, bit3/bit4 accept arrival on x / y only) | +32,+34 walk target (and previous position for the player)
| +38,+3a waypoint | +3c,+3e s16 x range, +40,+41 u8 y range.
Anim tables: 0x1744 (player) / 0x175e (NPC) indexed by state+dir.

## Room geometry
Floor contour polyline at 0x1832 (count, then (x,y) pairs), rasterized into the column table 0xa68[320] (0cc4).
Door table 0x752 (6 bytes each, count 0xa8): {u8 type, s8 dest room, s16 x1, s16 x2}; door y comes from 0xa68.
Obstacle rects 0x1286 (u8 x1,y1,x2,y2 in half-pixel x; count 0x1284) are built per room (0612).
Depth list DSPTR(0x3270): count byte, then {y,id} pairs sorted by y; id 0x10 = room object, <10 = actor.

## Hardware / timing / tricky for the port
* main reads a far ptr from the IVT at 0000:025c (int 0x97) = launcher param block (byte 7 sound option, byte 8 language); needs plat_ (TODO(port)).
* main calls the driver installers sub_11b2_0001 (video), sub_0ebb_0301 (int 9), sub_0d7d_000a (int 8),
  sub_0e9f_00c1 (sound driver at int 0xf0), sub_0dc5_0780 (DOS time), sub_0c9b_0e15 (CPU test via FLAGS).
* main stores the far code pointer 07fe:00b2 into DSPTR(0x2d40) (file-error callback) -> `(uint8_t *)sub_07fe_00b2`.
* Busy-waits on keyboard ISR state need plat_yield(): 030c (wait release/press of 0x2d4e), 05cd (pause loops on
  0x2d4e/0x2d4a/0x2d54), 1cf8 (wait while scancode 0x27 or 0x1c is held).
* 1e2e frame limiter: reads 0x2840 (set by timer ISR every 50 ticks = frames drawn) and calls the
  vsync wait sub_118f_00de [0x1736] times.
* main checks farcoreleft() (sub_0791_05f7) < 0x4f970 -> fatal "NO MEMORY FREE"; sub_0000 purges below 20000.
  The port's farcoreleft must return a large value.
* Huge ptr arithmetic: 052f/0564 add 32-bit offsets; 0612 uses ptr-2 / ptr-1.  0483 can use slot index -1 (writes before the table at 0x922) if no slot frees up; keep it literal.
* 1831/188d return an uninitialised local if the polyline is empty (TODO(port): initialise to 0).
* 0b9b frees buffers without nulling the DS pointers; 097e does not null 0x3286.
* 0cf2 compares the actor pointer with DSADDR(0x11a) to detect the player.
