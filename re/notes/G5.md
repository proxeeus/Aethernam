# G5 - segments 0714, 0791, 0a21

## 0714 - actor walking & collision (adventure/room view)
* Actors: 10 records of 0x46 bytes at DS 0x11a (actor 0 = player). Used fields: +0 x, +2 y (feet),
  +0x0c room, +0x0e anim, +0x12 facing (1 up, 2 right, 3 down, 4 left), +0x23 half width (u8),
  +0x24 height (u8), +0x25/+0x26 last collision kind/index (u8; kind 8 = walking through an exit,
  collisions disabled), +0x2a hit points, +0x30 walk flags (bits0-1: 1/2 = which axis to walk
  first, 0x4 = saved target valid), +0x32/+0x34 target, +0x38/+0x3a saved target.
* Actor box = {x-hw, y-h, x+hw, y}; overlap test sub_0e9b_000c(rectA, rectB). random(n): sub_0053_05f6.
* Collision code = (kind << 8) | index: 0x100 horizon/side border, 0x200 bottom (y > 0xab),
  0x300 obstacle rect (DS 0x1286, count u8 0x1284, coords x/2,y bytes), 0x400 exit zone
  (DS 0x752, 6 bytes, count 0xa8), 0x500 floor object (DS 0xa18, 8 bytes, count 0xf0),
  0x600 other actor in same room (DS16(0xce)). sub_0714_06c7 is the combined test,
  sub_0714_075b stores the result in the actor and fires room exits for the player.
* Floor model: DS 0xa68 = 320-byte table, min walkable y per screen column (loaded per room by
  sub_0053_0cc4). Walk targets are clamped to x in [hw+1, 0x13e-hw], y in [horizon+h+2, 0xab].
## 0791 - sound driver glue, palette, special FX, player HP, quit
* Music/sfx go through a resident Infogrames driver on `int 0xF0` (wrappers in seg 0e9f, other
  group): sub_0e9f_0013(val, 0, cmd) music cmd (0x40 stop, 0x80 play, 0x2000 set volume,
  0x8000 ramp volume), sub_0e9f_006f(n, 0, flags) play effect n from bank (0x40 = stop, 0x80 play,
  0xa0 play variant), sub_0e9f_01a8 start song, sub_0e9f_017e register sfx bank. sfx ducks music to 50.
* Resources: MUS.PAK (name ptr DSPTR(0x18b0); init code may patch char 2 to 'b' for another
  sound card). sub_0fa2_0008(name, index, dest) loads PAK entry index into dest (0 = failure).
  Entry 1 = sound-effect bank -> DSPTR(0x17c4) (0x2968 bytes); songs -> DSPTR(0x17c0) (0x5208).
  DS16(0xe8) music volume (0 off), DS16(0xea) sfx on, DS16(0xd6) current song.
* Palette: sub_0791_067f(pal) = set whole 256-colour DAC from 8-bit RGB (>>2), in two halves of
  128 colours each after a vertical retrace (sub_0e3f_0104 polls port 0x3da). sub_0791_0187(level)
  = red tint: r' = r + ((r+g+b+100)/4 - r)*level/16, g' = g*(16-level)/16, b' likewise
  on base palette DSPTR(0x304c). FX mode DS16(0x10c): 3 particles, 4 tint (loop sub_0596_0059).
* Particles: DS 0x30ae, 8-byte {x,y,vy,vx}, count 0x303e, origin 0x3036/0x3038, timer 0x3260.
  Gravity +1/frame; a particle that falls below y = 0x8c+rnd(10) is stamped as a colour-0x37
  pixel into background buffer DSPTR(0x3056) (draw ptr 0x2d38 swapped) and respawned. Drawing: sub_1100_00c0(col) set pixel colour, sub_1100_000b(x,y) pixel,
  sub_1040_0006(x1,y1,x2,y2,col) line.
* Lightning: same array reused as {x1,y1,y2,x2}, count 0x1740 (queued by script 03dd_1352);
  each bolt = 10 jittered segments, colours 0xc0-0xcf (LFSR rng sub_0f21_0004 -> DS 0x2d1a/0x2d1c).
* Sprinkle: sub_0791_0506 random colour-1 pixels/crosses in a rectangle (script 03dd_13a6 sets
  DS 0x3020 rect + flag 0x32a0).
* Player HP (DS16(0x144) = actor[0].hp, max 99): +1 every 512 ticks of DS32(0x1fdc); 0 -> death
  sequence via sub_03dd_1147(0). sub_0791_0638 = damage actor.
* sub_0791_05f7 = coreleft (sub_0f27_0004(-1L)); callers test >= 0x4f970 etc: return a big constant.
* sub_0791_0665 = quit: restore int 8/int 9 vectors, shut driver, restore video, exit(). Called
  WITHOUT an argument, so exit status is stack garbage -> use exit(0).
* Dead code: far fn 0791:0475 (lin 0x7d85, no callers, not in listing), 32-step screen effect.
## 0a21 - vector-shape morph builder (sub_0a21_0005)
* Shape resource: +0 u16 offset to frame table; table entries 4 bytes, word 0 = frame offset
  relative to table. Frame: u8 flags (bit0 = coords are s8, else s16), u8 polygon count, then
  polygons: u8 colour, u8 npoints, u16 param, npoints x (x,y).
* Output is itself a one-frame shape: {4,0,4,0} header, frame at +8 (flags 0, count at +9),
  each polygon: colour, npts=max, paramA, paramB, then npts x {xA,yA,xB,yB} (s16, offsets added).
  Polygons are paired by index; missing points repeat the last point of the shorter polygon;
  unequal colours or a missing polygon produce collapse-to/grow-from-first-point polygons.
  Consumer: sub_0596_0b28 (renders at t = step<<8/steps), sub_07fe_0ff1 (intro/cutscene).
* All loop state lives in DGROUP 0x32e0..0x3491 (see globals); scratch polygons are 200 bytes
  each (max 49 points) - no bounds check in the original.
## Port notes / hardware
* HW only in callees (other groups): int 0xF0 driver, DAC 0x3c8/9, retrace 0x3da, int 21h.
* No busy-wait loops inside G5 functions (sub_0791_067f's 2 retrace waits are in the callee).
* Far pointers kept in DGROUP by 0a21 (0x3474/0x347a/0x3486/0x348a) point into DGROUP or the
  caller's buffer: use DSPTR() slots. 0714 functions take far ptrs to int16 (P16(p)).
