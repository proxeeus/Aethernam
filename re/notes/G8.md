# G8 - segment 0a86: exterior 3D landscape view + main game loop

## Role
Eternam's outdoor mode: a first-person walk over 5 islands (zone 0..4, DS16(0x1fd6)) drawn as
flat-shaded height-mapped tiles + scaled sprites, with a day/night palette cycle. `sub_0a86_154d` is
the top-level game loop (lcall'd at the end of main `sub_0053_2014`, never returns); indoor scenes
run inside it via `sub_0053_1f74(scene)`.
3D math/clip/sky/actors live in seg 0c9b (G7), polygon fill in sub_0d84_0002 (G9); 0a86 is the glue:
loading, cell management, painter's-order drawing, palette cycling, scene transitions.

## World geometry
* World 0x4000 x 0x4000, tile = 0x200 units (32x32 tiles), sector = 0x1000 (4x4 sectors).
* Map (i<N>.dat): u16 ntiles; 0x800 map = 32x32 {u8 tile type, u8 attr}; ntiles u16 offsets
  (-> DSPTR(0x34ca)); tile geometry (-> DSPTR(0x34b2)).
* Tile geometry record: u8 nobj, u8 npoly, nobj*4 bytes objects, then npoly x {u8 n, u8 color,
  n x (u8 x, u8 y) grid coords (*8 by sub_0c9b_0744)}. Polygon side = sign(x0 - y0) of its first vertex.
* Cell (DSPTR(0x34aa)+k*0x400, k=0..3, drawn k=3..0 back to front):
  +0x000 transformed object points (4 words each: screen x, depth, screen y, flags)
  +0x320 fptr tile geometry (NULL = cell outside map), +0x324 u16 nobj, +0x328/+0x32a cell world x/y,
  +0x32c/+0x32d u8 ground colors of the two triangles (0x0303 = sea), +0x334 u8 height grid
  (row stride 0x41: corners [0],[0x40],[0x41],[0x81]).
* Object flags: 0x80 = animated (index &0x1f, sub_0a86_08d3; also proximity trigger sub_0c05_0400 when
  depth<25), 0x20 = special (sub_0936_0876), else static sprite (index &0xff, sub_0a86_081f).
  Sprite scale = 0xa00/(depth+30) (static) or 0x61a8/(depth+30) (animated).
* Which 4 cells: tile + neighbours chosen from heading octant + half-tile bits (tables 0x202f, 0x201f).
## Sector sprite bank (DSPTR(0x3498), 0x38270 bytes, > 64K!)
Loaded from "i<zone>.PAK" entry 0x2153[zone*16+sector] at +0x294 (L = DSPTR(0x3492)).
L header: +4 s32 offset to 10 sprite offsets (s32, relative to that table), +8 s32 offset to anim
table (32 x s32 offsets -> {u8 cur frame, u8 nframes, 8-byte frame records (byte0 = sprite)}),
+0xc u16 offset of free space where sub_1110_01bc writes 15 downscaled copies of each sprite.
Bank header: s32 [10][16] offsets (bank-relative, scale 15 = original) at +0, {u8 halfw, u8 h}[10] at +0x280.
## Palette / time
* Time DS32(0x1fdc); every 64 half-ticks sub_0a86_0000 steps phase(0..8)/step(0..count=16):
  interpolates 5 sky colors (0x204f table) -> gradient palette 192..255 (exterior) or 224..255,
  scales by brightness 0x20ef (x/16, min DS8(0xd2)), uploads. In exterior (+1/tick) the condition
  holds on two consecutive ticks -> 2 steps per 128 ticks (quirk, keep).
* Island ground colors 0x20f9 -> palette 186..191 (sub_0a86_0325); ground-triangle color = c + 0xba.
* Countdown mode (DS16(0x11c0)==1): DS16(0x1fe6) decremented per palette step, shown at (10,20).
## Resources
RESID.PAK entry 3 (exterior palette), entry 2 (two far pointers: DSPTR(0x3262), compass DSPTR(0x34c6)),
A99.PAK entry 0x36 (drowning animation), i0..i4.dat (island maps), i0..i4.PAK (sector sprite banks).
## Scene transitions (154d)
Door tables 0x21a4[20] / 0x2244[4] {zone,x,y,heading}: sub_0c05_0400 sets DS16(0xa2)=door when the
player's tile matches; on return the player is placed at that record (unless 0x1fe4 or code 8).
Codes 10..19 remapped via 0x226c/0x2276. Code 99 = overlay scene drawn over a snapshot (14ae/1519).
Island switch: zone0 x>0x3fde <-> zone1 x<0xc1c (two water tiles excepted from drowning in 01c6).
## Port hazards
* 154d has no return (infinite loop); present/yield happens via sub_0a86_0d96 -> 0c9b blitters,
  which touch the VGA screen (DSPTR(0x2d3c)) and increment DS16(0x2d66). Loop should plat_yield
  somewhere (e.g. in the present path) or the port hangs on no-op frames.
* Huge-pointer arithmetic (sub_0000_0395/050b/0312) in 0370 and 08d3 over the 230000-byte bank;
  offsets stored as s32 in the bank -> native `base + off` / `p - base`.
* RESID#2 contains far pointers that the loader (sub_0c66_0003) relocates: read them with FP(res),
  FP(res+4); loader must register those FP slots.
* 0c9b accesses DGROUP through CS (cs:X = DS:X-0x57e0): 0x1fc2..0x1fd0, 0x2284, 0x34a6, 0x2d38 are
  shared with G7 through that alias.
* sub_0a86_0000 intensity: (int16)((b-a)*step) via 16-bit mul then cwd/idiv - keep 16-bit wrap.
* 154d local [bp-2] (0x11bc copy) may be read uninitialised on the first pass (init 0 in C).
* 154d: pixel under player (sub_110c_000c(160,168)) == 4 means water -> 01c6. 14ae: 32-bit counter.
